# Changelog

All notable changes to DOOM Card will be documented in this file.

## [1.0.0] - 2025-11-12

### Added
- Initial release
- 3D ray-casting engine with DOOM-style rendering
- Three weapons: Pistol, Shotgun, Chaingun
- Enemy AI with idle, chase, and attack states
- Progressive difficulty system
- Keyboard and mouse controls
- Health and ammo HUD
- Particle effects for hits and explosions
- Synthesized weapon sound effects
- Pause menu
- Game over screen with statistics
- Level progression system
- Score tracking

### Features
- Full 3D first-person perspective
- Smooth mouse look with pointer lock
- Collision detection for player and enemies
- Dynamic enemy spawning based on level
- Health bars for enemies
- Crosshair targeting
- Responsive canvas rendering
